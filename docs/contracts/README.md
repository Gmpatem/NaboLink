- `02-billing-entitlement.md`: invoices, verified payments, allocation, renewals, partials, refunds, expiry.

For each contract use: Goal; Actors; Inputs; Preconditions; State machine; Invariants; Main path; Failure paths; Permissions; API events; Idempotency; Observability; Test examples; Open decisions.
